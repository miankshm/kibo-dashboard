## 1. 요구사항 명세 (Issue Content)
## Background
- 현재 Gross 기준으로 검색한 후 '매출 기준'을 Net으로 변경하면 검색 버튼을 누르지 않았는데도 테이블의 강조 표시(초록색)가 Net 컬럼으로 즉시 변경됨.
- 검색 조건은 변경되었지만 실제 검색은 수행되지 않았으므로 현재 조회 결과는 유지되어야 함.
- 또한 Net 기준으로 검색해도 Uber Eats와 DoorDash 컬럼이 Gross 값 그대로 표시되고 있음.

## Requirements
- '매출 기준(Gross / Net)'을 변경해도 검색 버튼을 누르기 전까지는 현재 검색 결과와 테이블 표시를 유지할 것.
- 검색 버튼을 눌렀을 때만 선택한 매출 기준(Gross / Net)을 적용하여 결과를 갱신할 것.
- 테이블의 강조 표시(초록색 컬럼)도 실제 검색이 수행된 이후에만 변경할 것.
- Net 기준으로 검색한 경우 Uber Eats와 DoorDash 컬럼도 플랫폼 수수료가 반영된 Net 값으로 표시할 것.
- Gross 기준으로 검색한 경우에는 기존 Gross 값을 표시할 것.

## Expected Result
- 검색 조건을 변경하는 것만으로는 현재 조회 결과가 변경되지 않음.
- 검색 버튼을 눌렀을 때만 선택한 매출 기준이 검색 결과에 반영됨.
- Net 기준 조회 시 Uber Eats와 DoorDash 컬럼이 Net 금액으로 표시되어 테이블의 모든 금액이 선택한 기준과 일관되게 표시됨.
