## 1. 요구사항 명세 (Issue Content)
지금 지점 선택하지 않은 상태인 '전체 보기' 상태에서는 두 지점의 합계가 표시되지 않고 'woodbridge' 의 매출만 표시되는데, '전체 보기' 상태에서는 두 지점의 총합으로 표시해줘

## 2. 반영된 최종 스펙 (AI 작업 결과물)

- UI:
- `SalesSummary`에서 `selectedStoreId === all`일 때 `GET /api/v1/sales` 응답을 날짜 기준으로 합산하여 슬라이드 데이터를 생성하도록 수정.
- 기존에는 동일 날짜에 대해 지점별 row가 분리되어 마지막 row(woodbridge) 값이 대표로 보일 수 있었으나, 이제 동일 날짜 `st-clair + woodbridge` 합계가 표시됨.
- 전체 보기 조회 시 최근 일자 8개를 안정적으로 합산하기 위해 sales 목록 요청 limit을 `16`으로 조정(지점 2개 x 일자 8개 가정).

- API/DB:
- 변경 없음. 기존 엔드포인트 및 스키마 유지.
