## 1. 요구사항 명세 (Issue Content)
현재 매출 입력 필드(Card, Cash, Uber Eats, DoorDash 등)에서 입력 필드에 포커스가 있는 상태로 마우스 휠을 움직이면 숫자 값이 증가하거나 감하는데,

- 마우스 휠 스크롤로 인해 입력 값이 변경되지 않도록 수정
- 사용자가 페이지를 스크롤하는 과정에서 의도치 않게 매출 데이터가 변경되는 문제 방지

기대 결과:
- 입력 필드에 포커스가 있어도 마우스 휠 동작으로 값이 변경되지 않음
- 값 변경은 사용자의 직접 입력으로만 가능
- 실수로 인한 매출 데이터 변경을 방지하여 입력 안정성 향상
