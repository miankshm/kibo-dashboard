## 1. 요구사항 명세 (Issue Content)
현재 AI 분석 리포트가 단순 텍스트 나열 형태로 표시되고 있어 가독성이 떨어지며 AI 비서 경험이 부족함.

Layout 개선:
- 리포트 카드 내부 상하좌우 패딩 추가
- 섹션 간 여백 확대
- 긴 리포트 내용에 대해 스크롤 가능하도록 수정
- 모바일 환경에서도 가독성 확보
- 시각적 계층 구조 개선
- 섹션별 카드 분리
- 매출 요약, 요일 분석, 배달앱 분석을 독립적인 영역으로 구성
- 제목, 본문, 핵심 수치를 명확하게 구분

KPI 강조:
다음 항목은 카드 또는 배지 형태로 강조 표시
- 총매출
- 순매출
- 전주 대비 증감률
- 최고 매출 요일

예시:
┌─────────────┐
총매출
2,527
▲ 45.8%
└─────────────┘

아이콘 추가:
분석 영역별 아이콘 적용
📈 매출 요약
📅 요일 분석
🚚 배달앱 분석
💰 현금 관리
💡 AI 인사이트
🎯 추천 액션

AI 비서 경험 강화:
- 현재:
총매출: 12,527
순매출: 10,648
- 개선:
'이번 주 매출은 전주 대비 45.8% 증가했습니다.
특히 토요일 매출이 전체 매출의 57.1%를 차지하며 가장 높은 실적을 기록했습니다.'

핵심 인사이트 섹션 추가:
- AI가 분석 결과를 자연어로 요약
- 예시:
'💡 핵심 인사이트

이번 주 매출은 전주 대비 크게 증가했습니다.

매출의 대부분이 토요일에 집중되었으며,
Uber Eats 비중이 높은 것으로 확인됩니다.
추천 액션 섹션 추가'

목표:
- 단순 분석 결과 출력이 아닌 매니저를 돕는 AI 비서 경험 제공

## 2. 반영된 최종 스펙 (AI 작업 결과물)
### UI/UX 개선
- AI 위젯을 단순 텍스트 출력에서 카드 기반 레이아웃으로 개편.
- 리포트 영역에 카드 패딩/섹션 간 여백을 확대하고, 긴 내용은 스크롤 영역에서 안정적으로 조회 가능하도록 유지.
- 모바일에서도 KPI 카드와 분석 섹션이 깨지지 않도록 반응형 그리드(`2열/4열`) 구조 적용.
- 드로어 내부 컨테이너에 명시적 상하좌우 패딩(`px/pt/pb`)을 적용해 답답한 밀착 레이아웃을 해소.
- 플렉스 레이아웃에 `min-h-0`를 적용해 긴 리포트에서 스크롤이 항상 동작하도록 보정.

### 섹션 구조화
- 아래 분석 영역을 각각 독립 카드로 분리:
	- 매출 요약
	- 요일 분석
	- 배달앱 분석
	- 현금 관리
	- 핵심 인사이트
- 각 영역에 아이콘을 부여해 시각적 계층을 강화.

### KPI 강조
- 상단 KPI 카드에서 다음 핵심 지표를 강조 표시:
	- 총매출
	- 순매출
	- 전주 대비 증감률(상승/하락 아이콘 포함)
	- 최고 매출 요일

### AI 비서 경험 강화
- 기존 요약 문자열 외에 구조화된 `insights` 데이터를 받아 자연어 인사이트를 생성/표시.
- 핵심 인사이트는 증감률, 요일 집중도, 배달앱 의존도에 기반해 문장형으로 제시.
- 중복되는 원문 텍스트 블록은 제거해 카드 기반 요약 정보에 집중하도록 정리.

### 코드/데이터 변경
- `AIReport` 타입에 `insights` 필드를 확장.
- 워크플로우 상태(`AIAnalysisState`)에 `lastReportInsights`를 추가하여 UI에서 구조화 데이터 렌더링.
- AI 리포트 API 계약(기존 `summary`)은 유지하면서 추가 메타(`insights`)를 함께 전달하도록 확장.

### 영향 범위
- DB 스키마 변경 없음.
- 마스터 문서(01/02/03) 수정 없음.
