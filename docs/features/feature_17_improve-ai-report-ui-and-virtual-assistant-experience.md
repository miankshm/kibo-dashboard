## 1. 요구사항 명세 (Issue Content)
현재 AI 분석 리포트가 단순 텍스트 나열 형태로 표시되고 있어 가독성이 떨어지며 AI 비서 경험이 부족함.

Layout 개선:
- 리포트 카드 내부 상하좌우 패딩 추가
- 섹션 간 여백 확대
- 긴 리포트 내용에 대해 스크롤 가능하도록 수정
- 모바일 환경에서도 가독성 확보
- 시각적 계층 구조 개선
- 섹션별 카드 분리
- 매출 요약, 요일 분석, 배달앱 분석을 독립적인 영역으로 구성
- 제목, 본문, 핵심 수치를 명확하게 구분

KPI 강조:
다음 항목은 카드 또는 배지 형태로 강조 표시
- 총매출
- 순매출
- 전주 대비 증감률
- 최고 매출 요일

예시:
┌─────────────┐
총매출
2,527
▲ 45.8%
└─────────────┘

아이콘 추가:
분석 영역별 아이콘 적용
📈 매출 요약
📅 요일 분석
🚚 배달앱 분석
💰 현금 관리
💡 AI 인사이트
🎯 추천 액션

AI 비서 경험 강화:
- 현재:
총매출: 12,527
순매출: 10,648
- 개선:
'이번 주 매출은 전주 대비 45.8% 증가했습니다.
특히 토요일 매출이 전체 매출의 57.1%를 차지하며 가장 높은 실적을 기록했습니다.'

핵심 인사이트 섹션 추가:
- AI가 분석 결과를 자연어로 요약
- 예시:
'💡 핵심 인사이트

이번 주 매출은 전주 대비 크게 증가했습니다.

매출의 대부분이 토요일에 집중되었으며,
Uber Eats 비중이 높은 것으로 확인됩니다.
추천 액션 섹션 추가'

목표:
- 단순 분석 결과 출력이 아닌 매니저를 돕는 AI 비서 경험 제공
