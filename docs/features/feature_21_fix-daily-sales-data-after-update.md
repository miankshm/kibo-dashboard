## 1. 요구사항 명세 (Issue Content)
- 매출 데이터 수정 후 대시보드 및 매출 요약 카드에는 수정된 값이 정상 반영되지만, 매출 입력 드로어를 다시 열면 수정 전 값이 표시되는 문제 수정
- 수정하기 버튼으로 데이터 업데이트 후 최신 데이터가 조회되도록 수정
- 매출 입력 드로어 오픈 시 캐시된 값이 아닌 최신 DB 데이터를 불러오도록 검증
- 수정(Update) 이후 드로어 재진입 시 마지막으로 저장된 값이 모든 필드에 정확하게 표시되도록 수정
- 매출 요약 카드와 매출 입력 드로어 간 데이터 불일치 문제 해결

## 2. 반영된 최종 스펙 (AI 작업 결과물)
<!-- 코드 작업이 끝나면 변경된 스펙(DB/API/UI)을 여기에 요약해. -->

- API: `GET /api/v1/sales`는 드로어 재오픈 시 최신 DB 값을 보장하도록 동적 응답으로 처리되어 캐시된 응답을 재사용하지 않는다.
- UI: Daily Sales 드로어는 열릴 때와 저장/수정 이후 `dataVersion` 변경 시 선택한 날짜/지점 기준으로 매출 데이터를 다시 조회하고, 응답값으로 폼 전체 필드를 재설정한다.
- UI: 해당 날짜/지점에 저장 데이터가 없을 때만 숫자 필드를 기본값 `0`으로 초기화한다.
- UI: 조회 실패 시에는 `0`으로 초기화하지 않고 마지막으로 확인된 입력값 또는 최근 저장값을 유지한 채 오류 안내를 표시한다.
