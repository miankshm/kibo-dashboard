## 1. 요구사항 명세 (Issue Content)
현재 매출 추이 그래프와 현금 유입 분석 상세 내역의 날짜 표기 가독성을 개선하고자 함

- 매출 추이 그래프 X축 날짜 형식을 요일(월/일) 형태로 변경
- 현금 유입 분석 > 2주 상세 내역 날짜 형식을 요일(월/일) 형태로 변경
- 날짜와 요일을 한 번에 확인할 수 있도록 표시 방식 개선

현재 동작:
- 그래프 X축: 6월 22일
- 2주 상세 내역: 6월 22일

기대 결과:
- 그래프 X축: 월(6/22), 화(6/23), 수(6/24) ...
- 2주 상세 내역: 월(6/22), 화(6/23), 수(6/24) ...
- 날짜와 요일을 한 번에 확인 가능
- 날짜 정보 가독성 향상

## 2. 반영된 최종 스펙 (AI 작업 결과물)
<!-- 코드 작업이 끝나면 변경된 스펙(DB/API/UI)을 여기에 요약해. -->

- UI: 매출 추이 그래프의 일간 X축 날짜 라벨을 `요일(M/D)` 형식으로 변경해 요일을 먼저 확인할 수 있도록 수정함.
- UI: 현금 유입 분석의 2주 상세 내역 날짜 라벨을 `M/D(요일)` 형식으로 변경해 날짜 뒤에 요일을 함께 표시하도록 수정함.
- 범위: 프론트엔드 표시 포맷 및 대시보드 추이 라벨 생성 규칙만 변경했으며 DB/API 계약 구조 변경은 없음.
- 적용 파일: `lib/db-queries.ts`, `components/dashboard/CashFlowAnalysis.tsx`
