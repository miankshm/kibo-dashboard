## 1. 요구사항 명세 (Issue Content)
## Background
- 사이드바에서 '데이터 로드' 메뉴 선택 시 데이터 로드 페이지로 정상 이동함.
- 이후 다른 사이드바 메뉴를 선택해도 해당 섹션으로 이동하지 않음.
- '데이터 로드'를 제외한 현재 구현된 메뉴들은 메인 대시보드 페이지 내 섹션으로 이동하는 구조임.

## Requirements
- '데이터 로드' 페이지에서 '대시보드', '매출 요약', '현금 흐름', '홀리데이 비교', '일일 매출 입력' 메뉴를 선택하면 메인 대시보드 페이지로 이동한 뒤 해당 섹션으로 스크롤 이동할 것.
- 현재 페이지가 메인 대시보드가 아닌 경우에도 사이드바 네비게이션이 정상 동작하도록 수정할 것.
- 향후 별도 페이지(예: 설정)가 추가되더라도 페이지 간 네비게이션을 고려할 수 있는 구조로 구현할 것.

## Expected Result
- '데이터 로드' 페이지에서도 다른 메뉴를 선택하면 메인 대시보드의 해당 섹션으로 바로 이동함.
- 어느 페이지에 있든 사이드바 네비게이션이 일관되게 동작함.
- 페이지 이동과 섹션 이동이 자연스럽게 연결됨.
