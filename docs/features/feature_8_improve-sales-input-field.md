## 1. 요구사항 명세 (Issue Content)
현재 매출 입력 필드(Card, Cash, Uber Eats, DoorDash 등)에서 숫자 입력 시 다음과 같은 불편함이 있음

- 숫자 입력 필드 우측에 표시되는 숫자 증감(▲▼) 컨트롤은 사용하지 않으므로 제거
- 기본값 0이 표시된 상태에서 숫자를 입력하면 기존 0 뒤에 숫자가 추가됨 (예: 0123)
- 사용자가 입력을 시작하면 기본값 0은 자동으로 제거되고 입력한 값만 표시되도록 개선

기대 결과:
- 모든 매출 입력 필드는 일반 텍스트 입력 방식처럼 자연스럽게 숫자를 입력할 수 있어야 함
- 불필요한 숫자 증감 컨트롤 제거
- 기본값 0 상태에서 첫 입력 시 입력값으로 대체되어 사용자 입력 경험 개선

## 2. 반영된 최종 스펙 (AI 작업 결과물)
<!-- 코드 작업이 끝나면 변경된 스펙(DB/API/UI)을 여기에 요약해. -->

- UI: Daily Sales 모달의 모든 숫자 입력 필드(Card, Cash, Uber Eats, DoorDash, Cash & Carry, Tips, Actual Closing Cash)에서 우측 숫자 증감 컨트롤(▲▼)이 표시되지 않도록 처리함.
- UI: 기본값이 0인 상태에서 입력 필드에 포커스/클릭 시 0을 자동 선택하여 첫 숫자 입력이 기존 0 뒤에 붙지 않고 즉시 대체되도록 개선함.
- UI: 사용자가 입력값을 모두 삭제해도 필드에 0이 자동 재입력되지 않도록 변경하여 빈 상태 편집이 가능하게 개선함.
- 저장 로직: 숫자 필드가 빈 값(undefined)이어도 저장 시점에 각 필드를 0으로 정규화하여 정상 저장되도록 처리함.
- UI: 숫자 필드에서 `e`, `E`, `+`, `-` 입력을 차단하고 비숫자 형식 붙여넣기를 차단하여 숫자 입력만 허용하도록 보완함.
- 구현 방식: 숫자 입력 필드에 공통 클래스(`appearance` 기반)와 공통 포커스/클릭 핸들러를 적용해 입력 경험을 일관화함.
- 적용 파일: `components/forms/DailySalesForm.tsx`
- 범위: 프론트엔드 입력 UX 개선만 수행, DB/API/인증 로직 변경 없음.
