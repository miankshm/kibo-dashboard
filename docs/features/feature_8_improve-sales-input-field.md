## 1. 요구사항 명세 (Issue Content)
현재 매출 입력 필드(Card, Cash, Uber Eats, DoorDash 등)에서 숫자 입력 시 다음과 같은 불편함이 있음

- 숫자 입력 필드 우측에 표시되는 숫자 증감(▲▼) 컨트롤은 사용하지 않으므로 제거
- 기본값 0이 표시된 상태에서 숫자를 입력하면 기존 0 뒤에 숫자가 추가됨 (예: 0123)
- 사용자가 입력을 시작하면 기본값 0은 자동으로 제거되고 입력한 값만 표시되도록 개선

기대 결과:
- 모든 매출 입력 필드는 일반 텍스트 입력 방식처럼 자연스럽게 숫자를 입력할 수 있어야 함
- 불필요한 숫자 증감 컨트롤 제거
- 기본값 0 상태에서 첫 입력 시 입력값으로 대체되어 사용자 입력 경험 개선
