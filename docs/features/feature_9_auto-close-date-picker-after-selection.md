## 1. 요구사항 명세 (Issue Content)
현재 기준일(Date Picker) 선택 시 달력에서 날짜를 클릭해도 달력이 계속 열린 상태로 유지되는데 

- 사용자가 날짜를 선택하면 달력이 자동으로 닫히도록 개선
- 날짜 선택 후 별도로 달력을 닫기 위한 추가 클릭이 필요하지 않도록 수정

기대 결과:
- 사용자가 날짜를 클릭하면 선택한 날짜가 입력 필드에 반영됨
- 날짜 선택과 동시에 달력이 자동으로 닫힘
- 일반적인 날짜 선택 UI 동작과 일치하도록 사용자 경험 개선

## 2. 반영된 최종 스펙 (AI 작업 결과물)
<!-- 코드 작업이 끝나면 변경된 스펙(DB/API/UI)을 여기에 요약해. -->

- UI: Daily Sales 입력 모달의 기준일 Date Picker를 제어형 Popover로 전환하여 열림 상태를 컴포넌트 상태로 관리함.
- UI: 달력에서 날짜를 선택하면 선택값을 폼에 반영한 직후 Popover를 자동으로 닫도록 수정함.
- UI: 모달이 다시 열릴 때 이전 Popover 열림 상태가 남지 않도록 Date Picker 열림 상태를 초기화함.
- 적용 파일: `components/forms/DailySalesForm.tsx`
- 범위: 프론트엔드 UI/UX 동작 변경만 수행, DB/API/인증 로직 변경 없음.
