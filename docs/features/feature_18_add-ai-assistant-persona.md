## 1. 요구사항 명세 (Issue Content)
현재 AI 분석 리포트가 단순 데이터 출력 형태로 제공되고 있어 사용자와의 상호작용 및 AI 비서 경험이 부족함.

AI 비서 이름 부여:
- AI 분석 기능에 고유 이름 추가
- 단순한 AI 매출 분석 비서 대신 브랜드화된 AI 캐릭터('Kibo AI Manager') 사용

AI 비서 캐릭터 강화:
-리포트 상단 예시:

🤖 Kibo AI Manager

안녕하세요.
이번 주 매출을 분석했습니다.

가장 주목할 점은 토요일 매출 집중도와
배달앱 매출 증가입니다.

목표:
- 단순 분석 도구가 아닌 AI 비서 경험 제공
- 브랜드 아이덴티티 강화
- 사용자 친화적인 리포트 제공
- SaaS 제품의 완성도 향상

## 2. 반영된 최종 스펙 (AI 작업 결과물)
### UI/UX 변경
- AI 위젯 상단 타이틀을 브랜드형 페르소나명인 Kibo AI Manager로 고정 적용.
- 리포트 결과가 있을 때 최상단에 페르소나 인트로 카드(인사 + 핵심 포인트 요약)를 추가.
- 인트로 카드는 아래 3문장 구조로 표시:
	- 인사/분석 안내
	- 최고 매출 요일 기반 핵심 포인트
	- 배달앱 비중 기반 핵심 포인트

### 카피/브랜딩 변경
- ko/en 공통으로 AI 위젯 명칭을 Kibo AI Manager로 통일.
- 설명 문구를 도구형 안내에서 비서형 톤으로 변경해 사용자 친화적 경험 강화.

### 데이터/로직 연동
- 기존 insights 데이터를 재사용해 인트로 카드 문장을 동적으로 생성.
- 요일/배달 데이터가 부족한 경우에도 폴백 문구로 자연스럽게 렌더링되도록 처리.

### 영향 범위
- DB 스키마 변경 없음.
- API 계약 변경 없음.
- 마스터 문서(01/02/03) 수정 없음.
