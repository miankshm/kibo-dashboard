## 1. 요구사항 명세 (Issue Content)
## Description

현재 AI 분석 리포트가 단순 수치 요약 위주로 제공되고 있어 운영 의사결정에 도움이 되는 인사이트 추가 필요

### 📈 매출 요약

* 총매출 표시
* 순매출 표시
* 전주 대비 매출 증감률 표시
* 전주 대비 순매출 증감률 표시

### 📅 요일 분석

* 최고 매출 요일 분석
* 최저 매출 요일 분석
* 각 요일이 전체 매출에서 차지하는 비중 제공

### 🚚 배달앱 분석

* Uber Eats 매출 비중 분석
* DoorDash 매출 비중 분석
* 배달앱 전체 매출 비중 분석
* 플랫폼 수수료 적용 후 순매출 영향 분석
* Uber Eats(23%) 및 DoorDash(15%) 수수료 반영 결과 제공

### 기대 효과

* 단순 수치 조회가 아닌 운영 인사이트 제공
* 매출 추세 및 요일별 패턴 파악 가능
* 배달앱 의존도 및 수수료 영향 확인 가능
* 매니저의 인력 배치 및 운영 의사결정 지원


## 2. 반영된 최종 스펙 (AI 작업 결과물)
### AI 리포트 로직 확장
- `createAiReportInDb`에서 단순 요약 문자열 생성 로직을 운영 인사이트 중심으로 확장.
- 분석 기간과 동일 길이의 직전 기간을 계산하여 전주 대비 증감률(총매출/순매출)을 산출.
- 분석 기간 내 일별 총매출을 요일별로 집계해 최고/최저 매출 요일 및 요일별 매출 비중을 계산.
- 배달앱 매출 분석 항목 추가:
	- Uber Eats 매출 비중
	- DoorDash 매출 비중
	- 배달앱 전체 매출 비중
	- 플랫폼 수수료 총 영향 금액
	- 수수료 반영 후 배달앱 순매출

### 수수료 반영 기준
- Uber Eats: 23% 수수료 반영 (`0.77` 적용)
- DoorDash: 15% 수수료 반영 (`0.85` 적용)

### 리포트 출력 포맷 개선
- 리포트를 아래 섹션 구조로 생성:
	- `[매출 요약]`
	- `[요일 분석]`
	- `[배달앱 분석]`
- 기존처럼 `summary` 단일 텍스트 응답을 유지하면서, 내부 내용만 인사이트 중심으로 강화.

### 저장 데이터(insights) 확장
- `ai_analysis_reports.insights`에 아래 메트릭을 추가 저장:
	- 증감률(총매출/순매출)
	- 요일 분석 결과(top/low/분포)
	- 배달앱 비중 및 수수료 영향 메트릭

### 영향 범위
- DB 스키마 변경 없음
- API 엔드포인트 계약 변경 없음 (`POST /api/v1/ai/analyze` 유지)
- UI 컴포넌트 구조 변경 없음 (기존 AI 위젯에서 강화된 요약 텍스트를 그대로 렌더링)
