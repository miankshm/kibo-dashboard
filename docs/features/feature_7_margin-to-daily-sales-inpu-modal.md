## 1. 요구사항 명세 (Issue Content)
일일 매출 입력 모달의 콘텐츠가 모달 경계에 너무 붙어 있어서 답답하게 보이고 가독성이 떨어져. 모달 내부에 적절한 패딩을 추가하고 상하좌우 여백을 적용해서 가동성을 개선하도록 수정하렴



## 2. 반영된 최종 스펙 (AI 작업 결과물)
