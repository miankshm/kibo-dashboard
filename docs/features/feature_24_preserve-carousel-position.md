## 1. 요구사항 명세 (Issue Content)
## Background
- 매출 요약 캐러셀에서 이전 날짜 매출을 확인 중 Gross / Net 토글 시 캐러셀이 오늘 날짜로 초기화됨.
- 토글은 표시되는 데이터만 변경되어야 하며, 현재 보고 있는 날짜는 유지되어야 함.

## Requirements
- Gross → Net 또는 Net → Gross 토글 시 현재 캐러셀 위치 유지할 것.
- 사용자가 보고 있는 날짜의 매출 요약을 그대로 유지한 상태에서 데이터만 변경할 것.
- 캐러셀이 오늘 날짜로 초기화되지 않도록 수정할 것.
- 좌우 이동 상태 및 선택된 날짜 정보가 토글 후에도 유지될 것.

## Expected Result
- 사용자가 이전 날짜를 보고 있다면 토글 후에도 동일한 날짜에 머무름.
- Gross / Net 전환 시 데이터만 변경되고 캐러셀 위치는 변경되지 않음.
- 불필요한 캐러셀 초기화가 제거되어 사용자 경험 향상됨.
