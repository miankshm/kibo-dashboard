## 1. 요구사항 명세 (Issue Content)
## Background
- '매장 방문' 카드 제거 필요함.
- 현재 '매장 방문' 값은 '카드 결제 + 현금 결제'의 합계라 중복 정보임.
- 동일한 정보를 두 번 표시하여 대시보드 가독성 저하됨.

## Requirements
- 매출 요약 캐러셀에서 '매장 방문(Store Visit)' 카드 제거할 것.
- '카드 결제', '현금 결제', '배달앱(Uber+DoorDash)', 'Cash & Carry' 카드만 표시할 것.
- 캐러셀 레이아웃 및 간격 자연스럽게 조정할 것.
- Gross / Net 토글 시에도 카드 구성 동일하게 유지할 것.

## Expected Result
- 중복 정보 제거로 대시보드 단순화됨.
- 실제 매출 구성 항목만 표시되어 가독성 향상됨.

## 2. 반영된 최종 스펙 (AI 작업 결과물)

- DB: 변경 없음.
- API: 변경 없음.
- UI:
	- `Sales Summary` 캐러셀 카드에서 `매장 방문(Store Visit)` 카드를 제거함.
	- 카드 구성은 `카드 결제`, `현금 결제`, `배달앱(Uber+DoorDash)`, `Cash & Carry` 4개로 고정함.
	- 캐러셀 카드 그리드를 `lg:grid-cols-5`에서 `lg:grid-cols-4`로 조정해 레이아웃/간격을 자연스럽게 유지함.
	- Gross/Net 토글 시에도 동일한 4개 카드 구성으로 동작하도록 카드 데이터 생성 로직을 정리함.
