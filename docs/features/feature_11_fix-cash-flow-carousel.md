## 1. 요구사항 명세 (Issue Content)
현재 현금 유입 분석(Carousel)에서 기간 이동 방향이 직관적인 동작과 반대로 구현되고 있음

- 오른쪽 화살표 클릭 시 다음 2주 기간으로 이동하도록 수정
- 왼쪽 화살표 클릭 시 이전 2주 기간으로 이동하도록 수정
- 일반적인 캐러셀 및 날짜 탐색 UX와 일치하도록 방향성 개선

현재 동작:
- 오른쪽 화살표 → 이전 2주
- 왼쪽 화살표 → 다음 2주

기대 결과:
- 오른쪽 화살표 → 다음 2주
- 왼쪽 화살표 → 이전 2주
