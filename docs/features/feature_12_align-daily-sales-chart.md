## 1. 요구사항 명세 (Issue Content)
현재 일별(Daily) 매출 그래프는 현재일을 종료일로 하여 최근 7일 데이터를 표시하고 있는데, 일별 그래프 기준을 최근 7일이 아닌 현재일이 포함된 주(월요일~일요일) 기준으로 변경

예시:
- 오늘이 목요일인 경우: 월요일 ~ 목요일 데이터만 표시
- 금요일, 토요일, 일요일은 아직 해당 날짜의 매출 데이터가 없으므로 그래프에 포함하지 않음
- 오늘이 일요일인 경우: 월요일 ~ 일요일 전체 표시

기대 결과:
- 일별 그래프는 항상 현재일이 속한 주(월~일)를 기준으로 표시
- 미래 날짜는 그래프에 표시하지 않음
- 주간 매출 흐름을 직관적으로 확인할 수 있도록 개선
