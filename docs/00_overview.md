# [Detailed Prompt] Kibo Dashboard: AI 기반 통합 매출 관리 및 홀리데이 분석 시스템

## 1. 프로젝트 목적 및 핵심 가치 (Core Value)
*   **서비스 목표:** 기존 엑셀 기반 관리의 한계를 극복하고, **홀리데이(공휴일) 기준 과거 매출 데이터를 자동 조회**하여 효율적인 운영 및 인력 배치를 지원하는 AI 하이브리드 대시보드 구축.
*   **페인 포인트 해결:** 수동으로 과거 데이터를 찾는 번거로움을 자동화된 **이름 기반 홀리데이 그룹화** 로직으로 해결함.

## 2. 사용자 및 권한 구조 (Multi-Tenancy)
*   **사용자 구성:** 총 5명의 관리자가 2개 지점을 통합 관리함.
*   **권한 체계:** 모든 관리자는 동일한 권한을 가지며, 기존 관리자가 계정을 생성한 후 **이메일 초대**를 통해 신규 관리자를 추가하고 비밀번호를 설정하는 방식을 사용함.

## 3. 데이터 아키텍처 및 상세 필드 (Data Logic)
### 3.1 필수 테이블 설계
*   **Admins (관리자):** ID, 이름, 이메일 (인증용).
*   **Stores (매장):** ID, 지점 이름.
*   **Sales (매출):** 날짜, 매장방문결제, 카드결제(Tip 미포함), 카드팁, 현금결제, Uber Eats, Door Dash, 캐시앤캐리, 실제마감현금.
*   **Events Master (이름 기반 홀리데이):** 이벤트 이름 (예: Victoria Day).
*   **Events (날짜 기반 홀리데이):** 이벤트 마스터 ID, 해당 연도 날짜 (유동적 날짜 매핑 포함).

### 3.2 핵심 데이터 로직
*   **데이터 관계:** 관리자는 여러 매장과 매출 데이터를 관리하며, 매출 데이터는 특정 날짜를 기준으로 저장되나 **홀리데이 기간 포함 시 이벤트와 연계**하여 분석됨.
*   **수정 이력 시스템 (Audit Log):** 데이터 확정(Locking) 없이 상시 수정 가능하나, **수정 전/후 값, 수정자, 수정 시간, 수정 사유**를 반드시 기록하여 추적성을 보장해야 함.
*   **초기 데이터 마이그레이션:** 기존 엑셀 매출 데이터를 시스템에 일괄 반영할 수 있는 **Bulk Upload** 기능을 제공함.

## 4. 기능적 요구사항 (Functional Requirements)

### 4.1 대시보드 UI 구성
*   **상단 네비게이션:** 지점 선택 시 대시보드 전체 데이터가 해당 지점 기준으로 즉시 전환됨.
*   **매출 요약 카드:** 일/주/월 단위 매출 비교를 제공하며, **총매출/순매출 간 전환** 기능과 추이 시각화 그래프를 포함함.
*   **상세 매출 구분:**
    *   **일 매출:** 카드, 현금, 캐시앤캐리, 배달(Uber Eats, Door Dash)별 구분.
    *   **주/월 매출:** 주별/월별 매출 합계 제공.
*   **매출 입력 영역:** 관리자가 일일 매출 데이터를 시스템에 직접 입력하는 폼 제공.

### 4.2 분석 및 인사이트 기능
*   **현금 유입 분석:** 2주 단위 집계, **매출 기준 예상 현금 vs 실제 마감 현금 차액** 표시, 직전 2주 대비 증감 금액 및 증감률 제공.
*   **홀리데이 자동 비교:** 특정 홀리데이 선택 시, 과거 1~2년 또는 역대 동일 홀리데이의 매출 데이터를 **당일 기준**으로 자동 조회 및 시각화.
*   **AI 매출 분석 비서:** GPT-4o, Claude 3.5, Gemini 중 하나를 활용하여 선택된 기간의 핵심 인사이트를 자연어로 리포트(예: "Victoria Day 영향으로 배달 매출 증가").

## 5. 시각적 가이드 및 기술 스택
*   **UI 스타일:** 키보스시 브랜드 아이덴티티인 **블랙 & 그린(Black & Green) 톤**.
*   **디자인 레퍼런스:**
    *   **Square:** 매출 중심의 깔끔한 레이아웃.
    *   **Shopify:** 데이터 시각화 및 그래프 표현 방식.
    *   **Google Analytics:** 기간 간 데이터 비교 및 증감률 인터페이스.

## 6. 개발 및 운영 제약 사항
*   **분석 범위 제외:** 비정기적 이벤트(1+1 행사 등)의 매출 영향 분석은 포함하지 않음.
*   **인력 배치 지원:** AI가 직접 인력을 추천하지 않으며, 홀리데이 데이터를 기반으로 **사용자가 직접 판단할 수 있는 정보**만 제공함.
